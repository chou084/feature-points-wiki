# 單應性（Homography）

## 一句話定義
一個 3×3 矩陣所代表的影像對影像變換，可以把一張影像中的點對應到另一張影像中的位置。[S4]

## 直覺解釋
在三種情況下，單應性能精確或幾乎精確地描述兩張影像的關係：相機只繞著自己的中心旋轉、場景離相機很遠、或拍的是平面。[S4]

> 💡 白話詮釋（非來源原文）：想像把一張印好的照片拿在手上，平移、旋轉、放大縮小、往後傾斜，眼睛看到的形狀變化，都可以用一個單應性描述。

## 重點
- 不需要任何 3D 資訊，就能隨機產生並套用到任何 2D 影像上。[S4]
- 因為世界大多「差不多是平面」，單應性是描述「同一個 3D 點從不同角度看」的好模型。[S4]
- 隨機產生時，會把它拆成平移、縮放、平面內旋轉、對稱透視變形等簡單變換再組合，以免產生不合理的扭曲。[S4]
- 「單應性估計」常被當成評估特徵好壞的任務：用兩張圖的匹配點估出單應性，再和真正的單應性比對，看四個角落差了幾個像素。[S4] LiftFeat 也用同樣方式在 HPatches 上評估。[S5]

## 限制／常見誤解
- 對不是平面、又離相機很近的物體，單應性只是近似。[S4]
