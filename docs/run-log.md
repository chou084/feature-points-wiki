### 目前觀察（反思素材，之後整理）
- 「術語沒解釋」是自動 lint 抓不到的，只能靠人工 → 之後考慮在 ingest 的「討論」步驟就先列出新術語。
- 討論階段若只看搜尋摘要，可能漏掉細節 → 寫入前要再讀全文。
- 流程修改 #1 有效但不完整：術語問題從 3 個降到 2 個。漏掉的詞是「寫頁面時」才出現的 → 術語檢查不能只放在討論，寫完後的人工檢查仍要保留。
- 術語漏網的位置有規律：S2 是寫作時冒出的詞，S3 全在「實驗結果」段（方法名、數量級）。討論時的術語清單偏重「方法」段落。
- 矛盾檢查（lint b）往前移到討論階段很有效：S3 的衝突在寫入前就被發現，還變成了一張教學投影片。
- lint 本身也會錯（誤報）。每次修改 lint 都要用故意寫錯的資料重新驗證。
